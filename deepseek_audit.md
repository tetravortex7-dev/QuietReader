# QuietReader — аудит DeepSeek

Дата: 22.10.2026. Аудит выполнялся в режиме чтения; выводы ниже актуальны на момент создания файла.

## Уже закрыто

- [x] **OPDS: утечка учётных данных.** Пароль передаётся только по HTTPS и только на origin самого каталога. На сторонние хосты и по HTTP `Authorization` не отправляется.
- [x] **OPDS: остаточные риски.**
  - [x] Лимиты: фид — 10 МБ, OpenSearch — 1 МБ, скачивание — 1 ГБ (`src/opds/client.rs`).
  - [x] Удаление временного файла при ошибке или обрыве загрузки (`TempFileGuard`).
  - [x] `image::Limits` при декодировании обложек: 2048×2048 и 32 МБ (`src/opds/covers.rs`).
  - [x] Не более 4 параллельных загрузок обложек.
- [x] **Локализация новых сообщений.** Все 12 языков проекта; добавлено правило `17. Localization Policy` в `AGENTS.md`.
- [x] **Секреты.** Пароли OPDS и ключ DeepL вынесены из JSON в системное хранилище (`keyring` 4.2: Windows Credential Manager, macOS Keychain, Linux Secret Service). Старые значения мигрируются, `.bak`/`.corrupted` очищаются от секретов, файл настроек получает права `0600` на Unix и ACL только для текущего пользователя на Windows.
- [x] **Форматы и README.**
  - [x] Поддержка FB2.ZIP; сохранение `.fb2.zip` не превращается в `.fb2`.
  - [x] Кодировки TXT приведены в соответствие с README: CP1252, KOI8-R, CP866.
  - [x] `.xml` открывается как FB2 только при корне `<FictionBook>`.
  - [x] Добавлено определение RAR5; `.zip` с FB2 не считается комиксом.
  - [x] README и все 12 локализаций обновлены.
- [x] **Безопасность.**
  - [x] Убрано `unsafe` с ручным продлением времени жизни при выделении текста PDF (`src/app/pdf_view.rs`).
  - [x] Windows-ассоциации больше не удаляют `UserChoice` и не перезаписывают `OpenWithList`/`MRUList`.
  - [x] Локальный IPC вынесен в приватный каталог `ipc`: принимаются только обычные файлы, символические ссылки отклоняются, размер запроса ограничен 64 КиБ, число путей — 32, длина пути — 4096 байт, запись атомарная, права каталога и файлов ограничиваются.
  - [x] Папки комиксов не раскрывают символические ссылки; глубина обхода ограничена `MAX_FOLDER_DEPTH = 32`.
  - [x] При отсутствии системных каталогов настройки сохраняются в приватный каталог временных файлов, а не в текущую рабочую папку.
  - [x] Добавлены тесты IPC, приватных каталогов, глубины папок комиксов и резервного пути настроек.
- [x] **Производительность и UX.**
  - [x] PDF больше не парсится заново на каждую страницу и каждый текст: разобранный `hayro::hayro_syntax::Pdf` хранится в документе, а файл отображается в память через `memmap2`.
  - [x] CB7 распаковывается один раз при открытии: страницы сохраняются в приватный временный кэш и читаются с диска без повторной распаковки архива; кэш удаляется при закрытии документа.
  - [x] Поиск выполняется в фоновом потоке с отменой устаревших запросов; для PDF/DjVu добавлен поиск по текстовому слою с переходом на страницу. Сканы без текстового слоя пропускаются без ложных совпадений.
  - [x] Скачанные книги сохраняются в системную папку загрузок (`Downloads`/`XDG_DOWNLOAD_DIR`) с безопасным временным резервом.
  - [x] Снижена нагрузка на память: PDF читается через memory-mapped файл, для MOBI/AZW добавлены лимиты файла 150 МБ и распакованного текста 300 МБ с ограниченной PalmDoc-декомпрессией.
