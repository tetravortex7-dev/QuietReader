# 📖 QuietReader

**QuietReader** — быстрый, модульный и легковесный кроссплатформенный ридер электронных книг, документов, комиксов и манги для **Windows**, **Linux** и **macOS**, написанный на Rust (`eframe` / `egui`).

Приложение спроектировано по принципам **SOLID**: чистая архитектура, мгновенный отклик интерфейса, адаптивная типографика, защита от повреждений данных, встроенный нейросетевой синтез речи и полное отсутствие визуального шума.

---

## ✨ Основные возможности

### 📚 Поддерживаемые форматы

- **Текстовые книги и документы (Flowable Text)**:
  - **FB2 / FB2.ZIP** (`.fb2`, `.fb2.zip`) — полная поддержка структуры секций, вложенного оглавления (TOC), метаданных, стихов, цитат, эпиграфов и автоматическое распознавание кодировок (`UTF-8`, `Windows-1251`).
  - **EPUB** (`.epub`) — чтение OCF-контейнеров, навигация по `NCX` и `EPUB 3 Navigation Document`, извлечение структуры глав и метаданных.
  - **TXT / Markdown / Логи** (`.txt`, `.md`, `.markdown`, `.log`) — автоматическое определение кодировок (`UTF-8`, `UTF-16 LE/BE` с BOM, `Windows-1251`) и интеллектуальная разбивка текста на главы по заголовкам Markdown (`#`, `##`) или маркерам глав (`Глава`, `Chapter`, `Часть`, `Part`).
  - **DOCX / RTF / DOC** (`.docx`, `.rtf`, `.doc`) — парсинг современных и классических текстовых документов Office с извлечением структуры текста и форматирования.
- **Документы с фиксированной вёрсткой (Fixed-Layout)**:
  - **PDF** (`.pdf`) — векторная растеризация страниц с кэшированием текстур (на базе `hayro`), масштабированием, поворотом страниц и возможностью выделения/копирования текста мышью (`Ctrl + C`).
  - **DJVU** (`.djvu`, `.djv`) — многостраничный рендеринг документов и сканов книг с поддержкой закладок, навигации и независимым бэкендом.
- **Комиксы и манга**:
  - **Архивы комиксов**: `.cbz` (ZIP), `.cbr` (RAR), `.cb7` (7-Zip), `.zip`, `.rar`, `.7z` с изображениями (`JPEG`, `PNG`, `WebP`, `GIF`).
  - **Папки с изображениями**: открытие директории или отдельного изображения с автоматическим подхватом соседей в естественном алфавитно-числовом порядке (`Natural Sort`: `p1`, `p2`, ..., `p10`) и метаданными `ComicInfo.xml`.

### 🎙️ Озвучивание текста (Text-to-Speech / Чтение вслух)

В QuietReader встроена двухдвижковая система синтеза речи с плавающей панелью управления:

- **Edge Нейро (Microsoft Neural TTS)**:
  - Естественные высококачественные нейросетевые голоса Microsoft Azure (`Светлана`, `Дмитрий`, `Jenny`, `Guy`, `Aria` и другие).
  - **Полная автономность**: не требуется никаких учетных записей, API-ключей, токенов или подписок — нужен только доступ в интернет.
  - Автоматическое фоновое обнаружение доступных региональных нейроголосов.
  - Иконка-подсказка `?` с напоминанием о необходимости подключения к сети.
- **Системный синтезатор (Offline System TTS)**:
  - Локальные синтезаторы ОС (Microsoft SAPI / системные голоса Windows, Linux и macOS: Ирина, Павел и др.).
  - Работает полностью офлайн без подключения к интернету.
- **Возможности плеера озвучки**:
  - **Интеллектуальная фильтрация голосов**: автоматическое определение языка книги (из метаданных или структуры текста) с отображением релевантных дикторов и голосовых помощников именно на языке произведения.
  - **Мгновенное изменение скорости** (`0.8x`, `1.0x`, `1.25x`, `1.5x`, `2.0x`): темп речи переключается в реальном времени с нулевой задержкой.
  - **Бесшовная смена голоса на лету**: переключение между персонажами и языками в процессе чтения без зависаний потока воспроизведения.
  - **Следящая автопрокрутка**: текст плавно скроллится вслед за читаемым абзацем, текущий читаемый фрагмент выделяется подсветкой.
  - **Автоматический переход по главам**: по окончании главы воспроизведение автоматически переходит к следующей главе книги.
  - Точный статус воспроизведения: номер текущей главы и абзаца (`Гл. X, абзац Y/Z`).
  - Кнопки пошаговой навигации к следующему/предыдущему абзацу, пауза, продолжение и остановка.

### 🌍 Мультиязычный интерфейс (I18n)

QuietReader поддерживает **7 языков интерфейса** с мгновенным переключением на лету без перезапуска приложения:
- 🇷🇺 **Русский** (`Русский`)
- 🇬🇧 **Английский** (`English`)
- 🇫🇷 **Французский** (`Français`)
- 🇪🇸 **Испанский** (`Español`)
- 🇨🇳 **Китайский (упрощенный)** (`简体中文`)
- 🇯🇵 **Японский** (`日本語`)
- 🇵🇹 **Португальский** (`Português`)

**Особенности локализации:**
- **Автоматическое определение языка ОС**: по умолчанию приложение определяет язык системы (Windows, Linux, macOS) и автоматически запускается на родном языке пользователя.
- **Выбор в настройках**: переключение между режимом «Авто (Системный)» или любым конкретным языком в окне настроек (`Ctrl + ,` -> вкладка `Внешний вид` / `Appearance`).
- **Автоматическое сохранение**: выбранный язык сохраняется в профиле пользователя (`settings.json`).
- **Поддержка CJK-шрифтов без артефактов**: автоматический подхват системных восточноазиатских шрифтов Windows (Microsoft YaHei, SimSun, Yu Gothic), Linux (Noto Sans CJK, WenQuanYi) и macOS (PingFang SC, Hiragino Sans) гарантирует безупречный рендеринг иероглифов без квадратиков (`□`).

### 🎨 Цветовые темы и визуальный комфорт

В приложении доступно **7 специализированных тем оформления**:
1. **Сепия (Sepia)** — мягкий фон цвета пергамента и приглушенный кофейный текст. Снижает нагрузку на зрение при длительном дневном и вечернем чтении.
2. **Сумерки (Twilight)** — мягкий древесно-кофейный полумрак и теплый кремовый текст. Идеальный баланс для вечернего чтения: не слепит как сепия и избавляет от резкого контраста темного режима.
3. **Теплая (Warm)** — закатная бумага с янтарным оттенком и шоколадным шрифтом (в стиле Moon+ Reader), без синего спектра.
4. **Мятная бумага (Mint)** — пастельно-зеленый фон (в стиле PocketBook) и контрастный темно-зеленый шрифт, снимающий спазм глазных мышц.
5. **Светлая (Light)** — классическая дневная страница с естественной бумажной контрастностью и оптимизированными контрастными надписями на кнопках.
6. **Тёмная (Dark)** — глубокий приглушенный ночной фон со светло-серым текстом для чтения в полумраке.
7. **OLED (Абсолютный чёрный)** — 100% черный фон (`#000000`) с полным отключением пикселей на OLED/AMOLED-матрицах для максимальной экономии заряда батареи.

### 🖌️ Векторные иконки без шрифтовых зависимостей

Интерфейс использует **100% процедурную векторную графику**:
- Все иконки (файловые операции, папки, поиск, оглавление, настройки, полноэкранный режим, кнопки зума, автопрокрутка, закрытие, синтез речи, подсказки) отрисовываются через векторные примитивы.
- Полное отсутствие квадратиков `[?]` и битых глифов независимо от наличия установленных шрифтов в операционной системе.

---

### 🔍 Полнотекстовый поиск (`Ctrl + F`)

- Встроенный плавающий виджет поиска по текстовым книгам с автоматическим фокусом поля ввода.
- **Мгновенный переход**: при вводе запроса или навигации читалка сразу же открывает нужную главу и центрирует скролл на найденном абзаце.
- Счётчик совпадений вида `1 из N`, переход по `Enter` (следующее) и `Shift + Enter` (предыдущее).
- Выпадающий список результатов с превью контекста (с безопасной обработкой многобайтовых UTF-8 символов кириллицы).
- Активная подсветка найденного фрагмента янтарным маркером и контекстная подсветка остальных совпадений на странице.

---

### 📑 Многовкладочный режим (Tabs)

- Возможность держать открытыми сколько угодно книг и документов одновременно в любых комбинациях (например: `PDF` в первой вкладке, `FB2` во второй, `DJVU` в третьей, `CBZ`-манга в четвертой).
- Каждая вкладка изолированно сохраняет свою главу, страницу, масштаб и точную позицию скролла.
- Вкладки автоматически восстанавливаются при повторном запуске программы.
- Быстрое закрытие вкладки средней кнопкой мыши (СКМ) или кликом по крестику.

---

### 🗾 Режимы чтения комиксов, манги и PDF

- **Направление чтения**:
  - **Автоматически** (по тегу `<Manga>` в `ComicInfo.xml`), **Комикс (слева направо)** или **Манга (справа налево)**.
- **Режимы отображения**:
  - **Одиночная страница** — классический постраничный просмотр.
  - **Разворот (2 страницы)** — двухстраничный просмотр с опцией отдельного показа первой страницы (обложки).
  - **Вертикальная лента (Webtoon)** — непрерывная прокрутка страниц сверху вниз.
- **Масштабирование**:
  - По ширине окна, по высоте, по размеру страницы или оригинальный масштаб (`100%`) с плавным зумом `50%–300%`.
- **Поворот страниц**: поворот PDF и комиксов на 90°, 180° и 270°.

---

### 🚀 Автопрокрутка и панорамирование

- **Плавная автопрокрутка**: автоматическое непрерывное чтение текста со скоростью от 1 до 20 пикселей в секунду.
- **Панорамирование средней кнопкой мыши**: зажатие колёсика мыши позволяет плавно перетаскивать текст или ленту страниц вверх и вниз.

---

### 🛡️ Безопасность и надежность данных

- **Атомарное сохранение**: настройки и история чтения записываются через временный файл (`.tmp`) с атомарной заменой и автосозданием резервных копий (`.bak`), исключая повреждение данных при сбоях питания.
- **Защита архивов**: многоуровневая валидация путей внутри ZIP/RAR/7Z архивов для блокировки уязвимостей Path Traversal (`..`), предотвращения ZIP-бомб и жесткого лимита потребления памяти.
- **Асинхронная загрузка**: тяжелые документы парсятся в фоновом пуле потоков без микрофризов и блокировки UI.
- **Мультимониторная безопасность**: корректное восстановление координат окна при отключении внешних мониторов без выхода за пределы видимого экрана.

## 🚀 Сборка и запуск

### Требования
- **Rust** (актуальная стабильная версия, редакция 2024).
- Для сборки на **Linux** требуются системные библиотеки графического стека:
  ```bash
  sudo apt-get install -y libgtk-3-dev libxcb-render0-dev libxcb-shape0-dev libxcb-xfixes0-dev libxkbcommon-dev libssl-dev libasound2-dev
  ```

### Команды

```bash
# Запуск в режиме разработки
cargo run

# Открытие файла из командной строки
cargo run -- "C:\Books\sample.fb2"

# Запуск полного набора unit-тестов
cargo test

# Сборка оптимизированного релизного бинарника
cargo build --release
```

Релизный профиль настроен с `opt-level = "s"` и `lto = "thin"`, что обеспечивает компактный размер бинарника (~18 МБ) при максимальной скорости отклика. Готовый исполняемый файл размещается в корне проекта: `QuietReader.exe`.
