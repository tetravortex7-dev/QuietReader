# 📖 QuietReader

**QuietReader** — быстрая, легковесная и удобная читалка электронных книг, документов, комиксов и манги. Текущая релизная платформа — **Windows**.

Приложение открывает файлы мгновенно, не перегружено лишними меню, бережёт зрение и позволяет полностью погрузиться в чтение.

## Платформенный план

- **Сейчас:** Windows — единственная активная релизная платформа.
- **Далее:** Android.
- **После Android:** Linux и macOS.

Отсутствие сборок под Android, Linux и macOS на текущем этапе не является дефектом. Платформенная работа вне активной фазы выполняется только по отдельному запросу.

## 💎 Бесплатная версия и QuietReader Pro

QuietReader использует модель **Free / Pro Lifetime**: базовая читалка остаётся бесплатной навсегда, а расширенные возможности открываются одной бессрочной покупкой.

- **Free навсегда**: все поддерживаемые форматы книг, документов и комиксов (включая CBR/RAR), вкладки, локальная библиотека с тремя режимами отображения, 7 тем, закладки и цитаты, поиск, оглавление, сохранение прогресса, а также системный офлайн-TTS.
- **Pro Lifetime**: нейросетевые голоса Edge TTS, встроенный переводчик, собственные OPDS-каталоги с Basic Auth, инструменты фокуса (bionic reading, линейка чтения, шрифт OpenDyslexic), фоновая атмосфера и умная обработка сканов (Smart Dark и автообрезка полей).
- **Пробный период**: один раз доступен 14-дневный пробный период со всеми возможностями Pro. Банковская карта не требуется, автоматического списания нет.
- **Офлайн-активация**: ключ формата `QR1-...` проверяется локально по встроенному открытому ключу Ed25519. Приложению не нужен сервер лицензий и подключение к интернету.
- **Где активировать**: `Настройки → Система и файлы → QuietReader Pro` или кнопка Pro на верхней панели. Там же отображается текущий статус, кнопка запуска пробного периода и ввод ключа активации.
- **О программе**: вкладка `Настройки → О программе` показывает версию QuietReader, текущий статус Free/Pro, уведомление UnRAR (Copyright Alexander L. Roshal, бесплатная распаковка RAR и запрет использования кода для обратной разработки алгоритма сжатия RAR) и уведомление SIL Open Font License 1.1 для шрифтов OpenDyslexic и Lexend.

### Как ведёт себя приложение без лицензии

- Все настройки Pro сохраняются и не удаляются: после активации или запуска пробного периода они снова начинают действовать.
- Без действующей лицензии Pro-функции не применяются: Edge TTS переключается на системный офлайн-движок, OpenDyslexic заменяется обычным шрифтом, Smart Dark и автообрезка отключаются, фоновая атмосфера останавливается, перевод и собственные OPDS-каталоги становятся недоступны.
- Интерфейс не показывает ошибок и не блокирует чтение: при попытке включить Pro-функцию открывается диалог с предложением пробного периода или активации.
- Ключ лицензии и дата начала пробного периода хранятся в системном защищённом хранилище (Windows Credential Manager/DPAPI). Дата начала пробного периода дополнительно дублируется в настройках для восстановления, но не теряется при сбое хранилища.

## ✨ Что умеет QuietReader

### 📚 Читает любые форматы
- **Электронные книги**: FB2 (включая `.xml` с корнем `<FictionBook>`), FB2.ZIP, EPUB, MOBI, AZW, AZW3, PRC, TXT, Markdown (`.md`), LOG. Встроено интеллектуальное распознавание кодировок (UTF-8, Windows-1251, Windows-1252, KOI8-R, CP866), автоисправление повреждённого текста («кракозябр» / mojibake) в книгах MOBI/Kindle без ложных срабатываний на корректном UTF-8, точное извлечение PalmDoc-записей со снятием хвостовых флагов (trailing data), чистое оглавление без HTML-тегов и бесшовное распознавание глав в составных книгах KF8.
- **Текст и Markdown**: TXT и LOG распознают главы по шаблонам (`Глава`, `Chapter`, `Part`, `=== ... ===`), а Markdown показывает жирный, курсив, код, ссылки, списки и цитаты. Кодировку можно выбрать вручную: UTF-8, Windows-1251/1252, KOI8-R, CP866, UTF-16LE/BE.
- **Иллюстрации и таблицы**: EPUB, FB2, MOBI/KF8 и DOCX показывают встроенные изображения; таблицы FB2 и DOCX выводятся построчно. Изображения декодируются в фоне с лимитами размера и кэшем текстур.
- **Офисные документы**: DOCX, RTF, DOC — с извлечением сносок, концевых сносок и колонтитулов. Небольшие DOC-файлы читаются через OLE mini stream.
- **Документы и сканы**: PDF и DJVU с возможностью приближения, поворота страниц, копирования текста мышью и поиска по встроенному текстовому слою. PDF читается с жёстким лимитом размера, разобранный документ переиспользуется для всех страниц, а внутренние ссылки PDF открывают нужную страницу по клику.
- **Комиксы и манга**: архивы CBZ, CBR, CB7, ZIP, RAR (включая RAR5), 7Z, а также обычные папки с картинками (JPG, PNG, WebP). ZIP-архивы с FB2 автоматически открываются как книги, а не как комиксы. Страницы CB7 один раз распаковываются в приватный временный кэш и дальше читаются без повторной распаковки архива.
- **Всплывающие сноски**: в FB2 (`body name="notes"` / `comments`), EPUB (`epub:type="noteref"`, обычные ссылки вида `[4]` на `note`/`fn`/`ftn`-якоря, `aside` / блоки с `id`), DOCX (`w:footnoteReference`), MOBI (`filepos`/`#anchor`), RTF (`\footnote`) и DOC (сноски и концевые сноски) маркеры примечаний подсвечиваются акцентным цветом. При наведении или клике открывается карточка с текстом примечания, поэтому не нужно перелистывать книгу до конца. Для примечаний в отдельной главе в карточке есть кнопка «Перейти к примечанию» и возврат к прежнему месту чтения; если текст примечания недоступен, маркер не выглядит кликабельным. Файлы примечаний вне spine также индексируются.

### 🆕 Последние улучшения (0.7.1)
- **EPUB-сноски**: распознаются не только `epub:type="noteref"`, но и обычные ссылки `[4]` на якоря `note*`, `fn*`, `ftn*`, `n*`, `comment*` и `примеч*`; контейнеры примечаний определяются по `id`, а отдельные файлы примечаний вне spine индексируются.
- **Примечания по ссылке**: текст примечания теперь ищется по фактическому адресу ссылки, включая `span`-обёртки с произвольными `id` (например, `id14`) и отдельные файлы примечаний с любыми именами.
- **Переход к примечанию**: карточка показывает кнопку «Перейти к примечанию» и возврат к тексту; для недоступных примечаний маркер остаётся обычным текстом.
- **MOBI/Kindle**: автоисправление «кракозябр» больше не срабатывает на корректный UTF-8, добавлено восстановление текста, ошибочно перекодированного в CP1251.
- **MOBI-ссылки и сноски**: поддерживаются `filepos` и `#anchor`, а текст примечания открывается в общей карточке.
- **PDF-ссылки**: внутренние ссылки страниц стали кликабельными и ведут на нужную страницу.
- **Кодировка текста**: кодировку TXT/MD/LOG можно выбрать вручную в `Настройки → Система и файлы`; документ переоткрывается сразу.
- **RTF-сноски**: примечания извлекаются и открываются во всплывающей карточке.
- **DOC-сноски и концевые сноски**: примечания извлекаются из footnote- и endnote-поддокументов и открываются в карточке; небольшие DOC больше не теряют текст благодаря поддержке OLE mini stream.
- **Колонтитулы**: DOCX, RTF и DOC показывают верхний колонтитул в начале документа и нижний — в конце.
- **Обложки**: полка показывает обложки MOBI/AZW/AZW3 из EXTH/PDB и первых страниц CBR/CB7.
- **Markdown и текст**: Markdown получил inline-разметку, а TXT/LOG — распознавание глав по шаблонам.
- **Иллюстрации**: EPUB, FB2, MOBI/KF8 и DOCX показывают встроенные изображения; декодирование идёт в фоне, текстуры ограничены по размеру и количеству.
- **Таблицы**: FB2 и DOCX сохраняют строки и ячейки в читаемом виде.
- **DOCX-сноски**: примечания открываются в той же всплывающей карточке, что и в FB2/EPUB.
- **Комиксы**: первая страница в двухстраничном режиме показывается отдельно, добавлена предзагрузка соседних страниц.
- **Позиция чтения**: текстовые книги запоминают абзац, поэтому позиция устойчива к смене шрифта и ширины колонки.
- **Сохранение прогресса**: запись на диск выполняется не чаще одного раза в 8 секунд и принудительно — при смене главы, закрытии вкладки и выходе из приложения.
- **Оглавление**: добавлен фильтр по названиям разделов.
- **Поиск**: регистр и буквы `ё/е` не мешают находить совпадения, а в DJVU найденные фрагменты подсвечиваются на странице.
- **Обложки библиотеки**: кэш миниатюр ограничен 128 МБ и 256 текстурами с вытеснением давно не использованных.
- **TTS**: выбранные движок, голос и скорость речи сохраняются между запусками.

### 🌐 Онлайн-каталоги электронных книг (OPDS) — Витрина-магазин
- **Двухпанельная витрина каталогов**:
  - *Левая панель*: список подключенных библиотек с проверенными каталогами по умолчанию (Standard Ebooks, Project Gutenberg, Feedbooks) и возможностью добавления/удаления собственных серверов (Calibre, Kavita, Audiobookshelf) с поддержкой авторизации (Basic Auth). Свои каталоги и Basic Auth входят в Pro.
  - *Защита учётных данных*: логин и пароль передаются только по HTTPS и только серверу самого каталога. Для каталогов с авторизацией HTTP запрещён, а заголовок `Authorization` не отправляется на сторонние хосты из фида (CDN обложек, внешние ссылки на книги).
  - *Безопасное хранение секретов*: пароли OPDS, ключ DeepL и ключ лицензии Pro хранятся в системном защищённом хранилище (Windows Credential Manager/DPAPI, macOS Keychain, Linux Secret Service), а не в JSON-настройках и не в резервных копиях. Дата начала пробного периода также сохраняется в защищённом хранилище и дублируется в настройках для восстановления. Файл настроек получает права `0600` на Unix или ACL только для текущего пользователя на Windows. Если защищённое хранилище недоступно, секреты не записываются на диск, а в интерфейсе показывается предупреждение.
  - *Ограничения загрузки*: ответ фида ограничен 10 МБ, описание OpenSearch — 1 МБ, скачиваемая книга — 1 ГБ; временные файлы удаляются при ошибке. Скачанные книги сохраняются в системную папку загрузок пользователя (Windows `Downloads`, macOS `~/Downloads`, Linux `XDG_DOWNLOAD_DIR`), а при её недоступности — в приватный временный каталог. Обложки декодируются с лимитами, одновременно загружается не более 4 обложек.
  - *Основная область витрины*: стильная книжная витрина с удобной постраничной навигацией.
- **Хлебные крошки и умный поиск**:
  - Кликабельная цепочка навигации (хлебные крошки, например: `Главная › Жанры › Фантастика`) для мгновенного возврата на любой уровень.
  - Умная строка поиска: автоматический запрос через OpenSearch для поддерживающих каталогов и мгновенная локальная фильтрация по названию, автору и аннотации для простых каталогов.
- **Наглядное разделение категорий и книг**:
  - *Сетка разделов и жанров*: аккуратные компактные карточки-папки в 2–3 колонки с иконками и описанием.
  - *Книжные карточки*: асинхронная подгрузка и кэширование цветных миниатюр обложек (со стильными векторными обложками-заглушками в цветах активной темы читалки), имя автора, теги, краткая аннотация с возможностью разворачивания длинного текста.
- **Бесшовное скачивание и открытие в 1 клик**:
  - Индивидуальные кнопки для каждого доступного формата книги (`Скачать EPUB`, `Скачать FB2`, `Скачать PDF` и др.) с живым отображением статуса прямо на кнопке («Загрузка...» / «45%»). Скачанные файлы сохраняют корректное расширение, включая составное `.fb2.zip`.
  - Фоновое сохранение без блокировки интерфейса и автоматическое открытие загруженной книги в новой вкладке читалки с уведомлением «Книга скачана и открыта».

### 🔒 Безопасность и устойчивость
- **Файловые ассоциации Windows**: QuietReader регистрирует свои обработчики, но не удаляет `UserChoice` и не перезаписывает `OpenWithList`/`MRUList`. Выбранное пользователем приложение для формата сохраняется.
- **Защищённый локальный IPC**: обмен с уже запущенным экземпляром идёт через отдельный приватный каталог. Принимаются только обычные файлы (символические ссылки отклоняются), размер запроса ограничен, пути проверяются, а запись выполняется атомарно.
- **Безопасный обход папок комиксов**: символические ссылки не раскрываются, а глубина вложенности ограничена 32 уровнями, что предотвращает случайные циклы и обход посторонних каталогов.
- **Предсказуемое хранение настроек**: если системные каталоги (`APPDATA`, `XDG_CONFIG_HOME`, `HOME`) недоступны, настройки сохраняются в приватный каталог временных файлов, а не в текущую рабочую папку.
- **Безопасная работа с PDF**: выделение текста не использует небезопасные операции с временем жизни и указателями; размер файла ограничен, а разобранный документ переиспользуется между страницами.
- **Лимиты MOBI/AZW**: файл ограничен 150 МБ, распакованный текст — 300 МБ; декомпрессия PalmDoc выполняется с проверкой размера на каждом шаге и не может исчерпать память.
- **Лимиты изображений**: иллюстрации EPUB/FB2/MOBI/DOCX декодируются в фоне с ограничениями 8192×16384 и 128 МБ, а кэш текстур ограничен 24 изображениями и 192 МБ.

### 👁️ Фокус внимания и комфорт чтения (Pro)
- **Доступность**: инструменты фокуса входят в Pro. После окончания пробного периода сохранённые настройки остаются, но эффекты не применяются до активации.
- **Линейка для чтения (Фокус строки)**: полупрозрачная направляющая полоса плавно следует за курсором мыши и слегка приглушает остальной текст. Помогает не терять строку в плотном тексте, удерживать внимание и читать без зрительного переутомления (быстро включается клавишей `L` или кнопкой на верхней панели). В настройках можно выбрать высоту полосы (от 1 до 5 строк) и комфортную силу затемнения.
- **Бионическое чтение**: аккуратно выделяет первые буквы каждого слова полужирным начертанием. Глаз мгновенно схватывает опорные точки, а мозг легко достраивает слова целиком — это ускоряет чтение длинных глав и снижает усталость от больших объемов текста.
- **Шрифт для людей с дислексией (OpenDyslexic)**: встроенный специализированный шрифт с утяжелённым основанием букв. Он помогает удерживать визуальную форму символов и предотвращает их оптическое «переворачивание» или слияние при чтении.

### 🎙️ Читает книги вслух (Синтез речи / TTS)
- **Нейросетевые голоса (Edge Neural)**: живое, выразительное звучание без роботизированных ноток. Доступны в Pro при наличии интернета; в бесплатной версии используется системный офлайн-движок.
- **Офлайн-голоса (Системные)**: классические дикторы вашей операционной системы, доступные без подключения к сети.
- **Подбор дикторов под язык книги**: приложение само определяет язык текста и предлагает подходящие голоса.
- **Удобное управление**:
  - Мгновенное переключение скорости речи (`0.8x`, `1.0x`, `1.25x`, `1.5x`, `2.0x`).
  - Подсветка читаемого абзаца и плавная автопрокрутка страницы вслед за диктором.
  - Автоматический переход к следующей главе при завершении текущей.
  - Голос, движок и скорость речи запоминаются между запусками.
  - Наглядные подсказки при наведении на переключатель голосов с рекомендациями по настройке.

### 🌐 Встроенный переводчик (Google Translate & DeepL) (Pro)
- **Мгновенный перевод прямо при чтении**: переводите непонятные слова, фразы или целые абзацы без переключения в сторонние программы или браузер.
- **Два провайдера перевода**:
  - **Google Translate**: бесплатный перевод без необходимости регистрации и ключей доступа.
  - **DeepL**: высококачественный литературный перевод с поддержкой собственного API-ключа (как бесплатного Free-ключа с суффиксом `:fx`, так и Pro-тарифов). Ключ сохраняется в защищённом хранилище операционной системы и не попадает в файл настроек или его резервные копии.
- **Умное контекстное меню по правому клику мыши (ПКМ)**:
  - *Перевести абзац* — моментальный перевод всего текущего абзаца.
  - *Перевести только выделенное* — перевод выбранного фрагмента текста (выделение аккуратно сохраняется и не слетает при нажатии правой кнопки мыши).
- **Интерактивное всплывающее окно перевода**:
  - Автоматическое определение исходного языка текста.
  - Быстрая смена целевого языка и переключение провайдера (Google / DeepL) прямо на лету.
  - Копирование результата перевода в буфер обмена в один клик.
  - Красивые векторные иконки интерфейса, адаптированные под выбранную цветовую тему читалки.

### 🎨 Уют для глаз и настройка под себя
- **7 цветовых тем**:
  1. *Сепия* — мягкий цвет пергамента для комфортного чтения днём и вечером.
  2. *Сумерки* — тёплый древесно-кофейный полумрак, идеален перед сном.
  3. *Тёплая бумага* — янтарно-шоколадный оттенок без синего спектра.
  4. *Мятная* — пастельно-зеленый фон, снимающий усталость с глаз.
  5. *Светлая* — классическая белая бумага.
  6. *Тёмная* — ночной контрастный режим.
  7. *OLED (Глубокий чёрный)* — 100% чёрный фон для максимальной экономии батареи на ноутбуках и устройствах с OLED-экранами.
- **Индивидуальная типографика**: свободная настройка размера шрифта (`Ctrl +` / `Ctrl -`), выбор гарнитуры, поддержка шрифта Lexend (бесплатно) и OpenDyslexic (Pro), межстрочный интервал `1.1–2.0` и максимальная ширина текстовой колонки `520–1200 px`, чтобы строка не растягивалась на широких мониторах.
- **Плавная автопрокрутка**: читайте без рук по нажатию клавиши `A` с комфортной скоростью скролла или паузами между блоками текста.
- **Единые векторные иконки**: все кнопки, стрелки, индикаторы загрузки и предупреждения отрисовываются собственными векторными путями и наследуют цвет активной темы без Unicode-символов и эмодзи.

### 📑 Удобные вкладки и сохранение прогресса
- Открывайте сколько угодно книг и документов одновременно на независимых вкладках.
- Читалка автоматически запоминает страницу, главу, масштаб и точную позицию скролла для каждого файла.
- Позиция текстовых книг дополнительно привязывается к абзацу, поэтому не сбивается при смене шрифта, межстрочного интервала или ширины колонки.
- Прогресс записывается на диск не чаще одного раза в 8 секунд, а при смене главы, закрытии вкладки и выходе сохраняется принудительно: чтение не нагружает диск на каждом прокрутке, но позиция не теряется.
- При следующем запуске все открытые вкладки открываются там, где вы остановились.

### 📚 Локальная библиотека и визуальные профили
- **Три режима библиотеки** (доступны бесплатно):
  - **Полка** — карточки книг с обложками, названием, автором, статусом чтения и прогрессом. Три вида полки: **«Мини»** — компактный вертикальный список с небольшой обложкой и названием, **«Стандарт»** — текущие карточки, **«Макси»** — карточки с увеличенной обложкой. Все виды прокручиваются сверху вниз, выбранный вид сохраняется в `library.json`. Обложки извлекаются из EPUB (OPF), FB2/FB2.ZIP (coverpage), MOBI/AZW/AZW3 (EXTH/PDB), CBZ, CBR, CB7 и папок комиксов, а также из `cover.jpg`/`cover.png` рядом с книгой; миниатюры до 240×360 кэшируются в `QuietReader/covers` и загружаются в фоне. При отсутствии обложки рисуется векторная заглушка. Доступны поиск по названию, автору и имени файла, фильтры «Все», «Читаю» и «Завершено», а также действия «Открыть», «Отметить завершённой» и «Убрать из библиотеки». Кэш обложек ограничен 128 МБ и 256 текстурами: давно не использованные миниатюры вытесняются автоматически, поэтому память не растёт даже при большой библиотеке.
  - **Папка** — плоский список поддерживаемых книг из выбранной папки и отдельный блок недавних файлов. Сканирование выполняется в фоне, не блокирует интерфейс и не раскрывает символические ссылки; глубина ограничена 6 уровнями, а число записей — 2000. Скрытые элементы (имена, начинающиеся с точки) и неподдерживаемые форматы пропускаются, при превышении лимита показывается предупреждение. Если в папке книги найден `metadata.opf`, из него читаются `dc:title` и `dc:creator`, после чего книга автоматически добавляется на полку с точными названием и автором (импорт библиотеки Calibre).
  - **Только чтение** — минимальный стартовый экран без библиотеки, когда книга не открыта. После открытия документа библиотека скрывается, а верхняя кнопка «Библиотека» не показывается. Файлы можно перетаскивать в окно.
- **Два визуальных профиля**:
  - **Уютный (Cozy)** — мягкие скругления карточек (16 px) и более тёплые формы интерфейса.
  - **Студия (Studio)** — строгие компактные скругления (6 px) для спокойного рабочего вида.
- **Переключение в один клик**: режим библиотеки и визуальный профиль меняются кнопками на стартовом экране и сразу сохраняются.
- **Первый запуск**: при создании новой пустой библиотеки QuietReader добавляет на полку демонстрационную книгу `welcome_guide.fb2`. В ней есть обложка, метаданные, три коротких главы и сноска: она показывает чтение вслух, перевод по правому клику, линейку фокуса (`L`), атмосферу (`M`) и закладки (`Ctrl+D`). Существующие библиотеки и файл `welcome_guide.fb2` не перезаписываются.
- **Надёжное хранение**: библиотека хранится в версионированном `library.json` рядом с `settings.json`. Запись выполняется атомарно, перед заменой создаётся резервная копия `.bak`, а при повреждении основного файла библиотека восстанавливается из копии. Существующие недавние книги и прогресс импортируются в библиотеку один раз, новые открытые книги добавляются автоматически.
- **Статистика чтения**: на полке в профиле Cozy отображаются дни подряд, общее время чтения и число завершённых книг. Активное время учитывается по дням только при открытой книге и реальной активности (TTS, автопрокрутка или недавнее взаимодействие); данные хранятся по дням, включая 7-дневную активность. В нижней панели текстовых книг показывается оценка минут до конца главы из расчёта 220 слов в минуту.

### 🗾 Специальные режимы для комиксов и манги
- **Направление чтения**: слева направо (европейские комиксы) или справа налево (традиционная манга).
- **Варианты показа**: одиночная страница, двухстраничный разворот (как в бумажной книге) или вертикальная лента (Webtoon).
- **Масштабирование и поворот**: вписывание по ширине или высоте окна, свободный зум и поворот страниц на 90°/180°/270°.
- **Разворот с обложкой**: в двухстраничном режиме первая страница показывается отдельно, а дальше идут ровные развороты без смещения.
- **Предзагрузка**: следующая и предыдущая страницы подготавливаются в фоне, поэтому листание ощущается мгновенным.
- **Бережная память**: декодированные страницы кэшируются с лимитом 384 МБ; при превышении давно просмотренные страницы выгружаются, а изображения декодируются с ограничениями по размеру, поэтому большие тома не исчерпывают память.

### 🔍 Поиск и оглавление
- **Быстрый поиск (`Ctrl + F`)**: ищет слова по всей книге с моментальным переходом к нужному абзацу. Поиск выполняется в фоновом потоке и не блокирует интерфейс; смена запроса или закрытие книги отменяет устаревший поиск.
- **Устойчивый поиск**: регистр и буквы `ё/е` не мешают находить совпадения.
- **Поиск в PDF и DJVU**: ищет по встроенному текстовому слою и переходит на нужную страницу. Сканы без текстового слоя не дают ложных совпадений; для них требуется предварительное OCR-распознавание.
- **Подсветка в DJVU**: найденные фрагменты отмечаются прямо на странице, чтобы сразу видеть нужное место.
- **Оглавление (`B`)**: наглядная боковая панель глав с индикацией прочитанного и фильтром по названиям разделов.

## ⌨️ Горячие клавиши

| Клавиша | Действие |
| :--- | :--- |
| `O` / `Ctrl + O` | Открыть книгу или документ (файл) |
| `P` / `Ctrl + Shift + O` | Открыть папку с мангой, комиксом или изображениями |
| `L` | Включить / скрыть линейку для чтения (фокус строки) |
| `M` | Открыть / закрыть панель фоновой концентрации («Атмосфера и Фокус») |
| `A` | Запуск / пауза плавной автопрокрутки текста |
| `B` | Показать / скрыть оглавление книги |
| `V` | Включить / поставить на паузу чтение вслух (TTS) |
| `J` | Открыть / закрыть настройки |
| `Ctrl + F` | Поиск по тексту книги или по текстовому слою PDF/DjVu |
| `Enter` / `Shift + Enter` | Следующее / предыдущее совпадение в поиске |
| `Ctrl + W` / **Клик колёсиком по вкладке** | Закрыть текущую вкладку |
| `Ctrl + Tab` / `Ctrl + Shift + Tab` | Переключение между вкладками |
| `Ctrl + D` | Добавить быструю закладку или удалить существующую |
| `F` / `F11` | Полноэкранный режим без лишних рамок и панелей |
| `Escape` | Закрыть поиск, оглавление или выйти из полноэкранного режима |
| `←` / `→` | Переход между страницами |
| `↑` / `↓` | Плавная прокрутка вверх / вниз |
| `PageDown` / `PageUp` / `Пробел` | Постраничная прокрутка текста |
| `Ctrl + =` / `Ctrl + -` | Увеличить / уменьшить шрифт или масштаб |
| `Ctrl + 0` | Сбросить шрифт или масштаб по умолчанию |
| **Выделение текста (ЛКМ)** | Выделение фрагментов текста мышью для копирования или перевода |
| **Правый клик мыши (ПКМ)** | Контекстное меню абзаца: перевод абзаца или выделенного фрагмента, чтение вслух, копирование |
| **Зажатое колёсико мыши (СКМ)** | Плавное перетаскивание страницы (панорамирование) |

## 🚀 Запуск и сборка

### Запуск готовой программы
Просто запустите файл `QuietReader.exe` в корне папки. Программа не требует установки: настройки хранятся в системном профиле пользователя (`APPDATA`), а секреты — в системном хранилище учётных данных ОС.

### Сборка из исходного кода
Для сборки потребуется [Rust](https://www.rust-lang.org/):

```bash
# Запустить приложение
cargo run

# Собрать оптимизированный релизный файл
cargo build --release
```

Готовый файл появится в корне проекта: `QuietReader.exe`.
