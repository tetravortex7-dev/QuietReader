# 📖 QuietReader

**QuietReader** — быстрая, модульная и кроссплатформенная программа для чтения электронных книг, документов, комиксов и манги для **Windows**, **Linux** и **macOS**, написанная на Rust (`eframe` / `egui`).

Приложение спроектировано с упором на комфорт длительного чтения, мгновенный отклик интерфейса, безопасность при работе с архивами и отсутствие лишнего визуального шума.

---

## ✨ Основные возможности

### 📚 Поддерживаемые форматы
- **Текстовые книги и документы (Flowable Text)**:
  - **FB2 / FB2.ZIP** (`.fb2`, `.fb2.zip`) — полная поддержка структуры секций, вложенного оглавления (TOC), метаданных, эпиграфов, стихов, цитат и автоматическое определение кодировок (`UTF-8`, `Windows-1251` и др.).
  - **EPUB** (`.epub`) — чтение контейнера OCF, навигация по `NCX` и `EPUB 3 Navigation Document`, извлечение метаданных и текста глав.
  - **TXT / Markdown / Логи** (`.txt`, `.md`, `.markdown`, `.log`) — автоматическое распознавание кодировок (`UTF-8`, `UTF-16 LE/BE` с BOM, `Windows-1251`) и интеллектуальная разбивка текста на главы по заголовкам Markdown (`#`, `##`) или главам (`Глава`, `Chapter`, `Часть`, `Part`).
- **Документы с фиксированной вёрсткой (Fixed-Layout)**:
  - **PDF** (`.pdf`) — растеризация страниц с кэшированием текстур (на базе `hayro`), адаптивным масштабированием и навигацией по страницам.
- **Комиксы и манга**:
  - **Архивы комиксов**: `.cbz` (ZIP), `.cbr` (RAR), `.cb7` (7-Zip) и обычные `.zip` с изображениями (`JPEG`, `PNG`, `WebP`, `GIF`).
  - **Папки с изображениями**: открытие директории с изображениями или отдельного файла изображения с автоматическим подхватом соседних страниц в естественном порядке сортировки (`Natural Sort`: `page1`, `page2`, ..., `page10`) и чтением метаданных `ComicInfo.xml`.

---

### 🎨 Комфорт чтения и персонализация
- **4 цветовые темы оформления**:
  - **Светлая (Дневная)** — мягкий светлый фон для дневного чтения.
  - **Сепия (Тёплая бумага)** — тёплые кремовые оттенки, снижающие нагрузку на глаза.
  - **Тёмная (Ночная)** — приглушённая тёмная палитра для чтения в сумерках.
  - **Чёрная (OLED)** — глубокий чисто-чёрный фон (`#000000`) для экономии заряда и минимального свечения на OLED/AMOLED-экранах.
- **Гибкая типографика**:
  - Выбор гарнитуры шрифта: **Без засечек (Sans-Serif)**, **С засечками (Serif)**, **Моноширинный (Monospace)** с подгрузкой системных шрифтов ОС.
  - Тонкая настройка размера шрифта (`12–36 пт`), межстрочного интервала, отступов между абзацами, красной строки (абзацного отступа), боковых полей и максимальной ширины текстовой колонки.
  - Выравнивание текста по левому краю или по ширине страницы.

---

### 🗾 Режимы чтения комиксов, манги и PDF
- **Направление чтения**:
  - **Автоматически** (определяется по метаданным `ComicInfo.xml`), **Комикс (слева направо)** или **Манга (справа налево)**.
- **Режимы вёрстки страниц**:
  - **Одиночная страница** — классический постраничный просмотр.
  - **Разворот (2 страницы)** — парное отображение страниц с опцией отдельного показа первой страницы (обложки) и настраиваемым зазором между страницами.
  - **Вертикальная лента (Webtoon)** — непрерывная прокрутка страниц сверху вниз.
- **Масштабирование (Fit Mode)**:
  - По размеру окна, по ширине, по высоте или оригинальный размер (`100%`) с дополнительным коэффициентом зума (`50%–300%`).

### 🧭 Навигация и управление
- **Боковая панель оглавления и закладок**:
  - Древовидное оглавление с мгновенным переходом к нужной главе и фильтрацией.
  - Система закладок с привязкой к конкретной книге, главе и позиции прокрутки.
- **Полнотекстовый поиск (`Ctrl + F`)**:
  - Быстрый поиск по всем главам документа с подсчётом совпадений, предпросмотром контекста и переходом между результатами (`Enter` / `Shift + Enter`).
- **Вкладки для одновременного чтения нескольких книг**:
  - Возможность открывать сколько угодно документов одновременно в разных вкладках в любых сочетаниях форматов (например: в первой вкладке `PDF`, во второй `TXT`, в третьей `FB2` или манга `CBZ`).
  - Каждая вкладка хранит собственную главу, страницу и точную позицию прокрутки; открытые вкладки автоматически восстанавливаются при следующем запуске программы.
- **Перетаскивание страницы зажатым колёсиком мыши (Панорамирование)**:
  - При зажатии средней кнопки мыши (колёсика) страницу можно плавно тянуть вверх или вниз в текстовых книгах и в режиме вертикальной ленты (Webtoon).
- **Быстрый переход к главе/странице (`Ctrl + G`)** и подробная карточка метаданных книги (`Ctrl + I`).
- **Полноэкранный режим без мигания (`F` / `F11`)**:
  - Полноценный borderless-режим поверх панели задач («Пуск») без переключения видеорежима монитора и без мерцания OpenGL.
- **Мультимониторная поддержка и сохранение состояния**:
  - Автоматическое сохранение позиции и размеров окна (включая компактные размеры), открытых вкладок, текущей главы и точной позиции прокрутки для каждой из 25 последних книг.
  - Защита от «застревания» окна за пределами экрана: если второй монитор был отключён, приложение автоматически определяет это и возвращает окно в рабочую область активного экрана.
- **Интеграция с ОС**:
  - Перетаскивание одного или сразу нескольких файлов (`Drag & Drop`) прямо в окно программы.
  - Предотвращение спящего режима и гашения экрана во время чтения.
  - Регистрация файловых ассоциаций в системе по желанию пользователя.

## ⌨️ Горячие клавиши

| Клавиша / Сочетание | Действие |
| :--- | :--- |
| `Ctrl + O` | Открыть один или несколько файлов в новых вкладках |
| `Ctrl + Tab` / `Ctrl + Shift + Tab` | Переключиться на следующую / предыдущую вкладку |
| `Ctrl + W` / **СКМ по вкладке** | Закрыть текущую вкладку |
| `Ctrl + F` | Открыть / закрыть поиск по тексту книги |
| `Ctrl + G` | Быстрый переход к номеру главы или страницы |
| `Ctrl + D` | Добавить или удалить закладку на текущей позиции |
| `Ctrl + B` / `T` | Показать / скрыть боковую панель (Оглавление и Закладки) |
| `Ctrl + I` | Информация о книге / документе |
| `Ctrl + ,` | Открыть окно настроек |
| `F` / `F11` | Включить / выключить полноэкранный режим |
| `Escape` | Закрыть открытое диалоговое окно или выйти из полноэкранного режима |
| `←` / `→` | Предыдущая / следующая глава (или страница в комиксах/PDF, с учётом режима манги) |
| `↑` / `↓` | Плавная прокрутка текста вверх / вниз |
| `PageUp` / `PageDown` / `Space` | Постраничная прокрутка текста (с переходом между главами на границах) |
| `Home` / `End` | Переход в начало / конец текущей главы (или к первой / последней странице комикса) |
| `Ctrl + =` / `Ctrl + -` | Увеличить / уменьшить размер шрифта (или масштаб комикса/PDF) |
| `Ctrl + 0` | Сбросить размер шрифта (или масштаб) по умолчанию |
| **Зажатое колёсико мыши** | Перетаскивание страницы вверх или вниз движением мыши |

## 🏗️ Архитектура проекта

Проект построен по принципам **SOLID** и разделён на четыре независимых слоя:

```text
src/
├── main.rs                 # Точка входа, инициализация окна и мультимониторной геометрии
├── settings.rs             # Персистентные настройки, история чтения, атомарное сохранение и миграции
├── platform.rs             # Платформозависимые сервисы ОС (ассоциации файлов, шрифты, экран, мониторы)
├── core/
│   └── mod.rs              # Ядро приложения (ReaderCore): навигация, прогресс, закладки, поиск (без UI)
├── document/               # Бэкенды форматов документов и единый реестр (DocumentRegistry)
│   ├── mod.rs              # Контракты и трейты документов, лимиты безопасности архивов
│   ├── registry.rs         # Регистрация и диспетчеризация парсеров по расширению/типу
│   ├── fb2.rs              # Парсер FB2 и FB2.ZIP
│   ├── epub.rs             # Парсер EPUB 2 / EPUB 3
│   ├── txt.rs              # Парсер TXT, Markdown и LOG с автоопределением кодировки
│   ├── pdf.rs              # Бэкенд рендеринга PDF
│   └── comic.rs            # Бэкенд комиксов/манги (CBZ, CBR, CB7, папки изображений)
└── app/                    # Слой представления и пользовательского интерфейса (egui)
    ├── mod.rs              # Координация UI, управление вкладками, обработка ввода и окна
    ├── tabs.rs             # Модуль вкладок (BookTab, TabsBar) для одновременной работы с несколькими книгами
    ├── text_view.rs        # Отрисовка текстовых книг, кэширование вёрстки и подсветка поиска
    ├── comic_view.rs       # Просмотрщик комиксов, манги и PDF с кэшем текстур
    ├── toc_view.rs         # Боковая панель оглавления и закладок
    ├── settings_view.rs    # Интерфейс настроек типографики, тем и режимов чтения
    ├── dialogs.rs          # Модальные окна поиска, информации о книге и переходов
    ├── autoscroll.rs       # Перетаскивание страницы зажатым колёсиком мыши
    ├── document_loader.rs  # Фоновая асинхронная загрузка документов в рабочем потоке
    ├── theme.rs            # Цветовые палитры тем оформления
    └── fonts.rs            # Инициализация и подгрузка шрифтов
```

### 🛡️ Надёжность и безопасность данных
- **Атомарное сохранение настроек**: запись настроек и прогресса чтения выполняется через временный файл (`.tmp`) с последующим переименованием и созданием резервных копий (`.bak`) при миграциях или повреждении JSON.
- **Защита при работе с архивами**: все архивы (`ZIP`, `EPUB`, `CBZ`, `CBR`, `CB7`) проходят проверку на Path Traversal (`..`), ограничение максимального числа файлов и лимиты объёма распаковки для предотвращения ZIP-бомб и исчерпания оперативной памяти.
- **Асинхронная загрузка**: открытие и парсинг тяжёлых книг, архивов и PDF выполняются в фоновом потоке без блокировки интерфейса.

## 🚀 Сборка и запуск

### Требования
- **Rust** (редакция `2024`, рекомендуется актуальная стабильная версия `rustup`).
- На **Linux** для сборки графического окна и диалогов потребуются системные пакеты:
  ```bash
  sudo apt-get install -y libgtk-3-dev libxcb-render0-dev libxcb-shape0-dev libxcb-xfixes0-dev libxkbcommon-dev libssl-dev
  ```

### Команды сборки
```bash
# Запуск в режиме разработки
cargo run

# Открытие конкретного файла из командной строки
cargo run -- path/to/book.fb2

# Запуск модульных и интеграционных тестов
cargo test

# Сборка оптимизированного релизного бинарника (opt-level = "s", thin LTO)
cargo build --release
```
